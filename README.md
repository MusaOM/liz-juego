# Liz y el Reino de las Colonias

Un juego de aventura para el celular (en horizontal): Liz, una microbióloga junior, recorre el Bosque Micelio y el Río Carmesí curando colonias enfermas para volver con Caleth.

Se juega aquí mismo, en el navegador. Todo va dentro de `index.html`: los dibujos, la música y los sonidos.
